# Security policy

Please **do not** open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/EmaLau/truenas-homelab-toolkit/security/advisories/new) instead.

Only the latest release is supported. Remember that the scripts run as root, that their settings files and the
backups contain secrets, and that lan-guard filters only TCP ports from one interface (see *Security* in the
[documentation](docs/documentation.md#security)).
